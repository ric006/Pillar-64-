FAQ

Straight answers about what Pillar is, what it leaves out, and what does not work yet.

The basics

What is Pillar 64?

A Linux desktop with a Windows 11-style layout and its own set of apps. It is built on Kubuntu 26.04 and KDE Plasma 6, running on Wayland.

Why "64"?

The name is Pillar 64 to keep it clearly separate from other projects called Pillar. It is the 64-bit system.

Is it Windows?

No. It looks and behaves in a way Windows users will recognise, but it runs on Linux. It does not run Windows programs by itself.

Can I install Steam or other programs?

Yes. Steam is not preinstalled so that people who do not want it are not carrying it. Download Valve's .deb installer and double-click it. Pillar Package Installer takes it from there. You can also use Pillar Software.

Privacy and updates

Does Pillar collect data?

Pillar ships with no telemetry and no advertising components. It does not send usage data anywhere.

Does it update itself?

No. Automatic update checks are off. Nothing installs unless you start it. From a terminal, the usual way is sudo apt update followed by sudo apt upgrade.

So what does Pillar download on its own?

One thing: the Microsoft fonts package, once, the first time the installed system is online. See Microsoft fonts for how it works and how to turn it off. The system integrity check can list the new font files afterwards, which is expected.

Is Snap included?

No. Snap packages are removed from Pillar.

System integrity check

What is the Pillar system integrity check?

Each time the installed system starts, Pillar checks that its important system files are the same as when they were installed, and shows the result on the start-up screen. It does not run when you try Pillar from the USB drive. The first start after installation sets the starting point.

Why did it report changes after my first restart?

If the computer was online, Pillar downloaded the Microsoft fonts after that starting point was set. The next check sees the new font files and lists them. This is expected and harmless. See Microsoft fonts.

What if it lists something that is not a font?

Then it is worth a look. Read the full result with cat /var/log/pillar-integrity.log, and do not ignore files you do not recognise.

Office files and fonts

Will my Word and Excel files open?

Yes. Pillar Word opens and saves .docx, and Pillar Excel Sheet opens .xlsx, .xlsm, .xls, .csv and .ods. Very complex documents with unusual features may not look identical.

Why does Word show different fonts at first?

The real Microsoft fonts arrive after your first restart with internet. Until then Pillar uses look-alike fonts with the same sizes, so layouts stay the same. More

Where is Calibri?

Microsoft does not offer Calibri for free download, so Pillar cannot install it. The look-alike font Carlito is used instead, and it matches Calibri's spacing.

What does not work yet

This is the first public test build. These are the known gaps.

  • Tested in VirtualBox only. It has not been tried on many real computers yet.
  • Pillar Excel Sheet has no charts or pivot tables, and does not read .xlsb files.
  • Pillar PDF cannot change the original text inside a PDF. Markup, forms and page tools work.
  • Pillar Disks cannot move or shrink partitions yet.
  • Pillar USB Creator does not support persistence on the USB drive.
  • There is no presentation app yet.
  • Video can look choppy in a virtual machine. That comes from the virtual machine, not Pillar.

Getting it

How big is the download?

3.9 GB. Use a USB drive of 8 GB or larger.

Is it safe to install on my main computer?

Not yet recommended. It is a first test build. Try it in VirtualBox or on a spare computer, and back up your files before installing on a real machine.
