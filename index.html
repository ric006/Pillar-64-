What Pillar is

Familiar

The layout will be familiar if you have used Windows 11: a Start menu, a taskbar along the bottom, and file, photo and settings tools where you expect them. It runs on Linux underneath, so it stays fast and does not need an account to use.

Quiet

Pillar ships with no telemetry and no advertising components. Updates are manual: nothing installs unless you start it. The one automatic download Pillar adds is the Microsoft fonts package, described on the fonts page. Pillar also checks its own system files at every start.

Its own

Word processor, spreadsheet, PDF tool, mail, browser, disk manager and USB maker, all made for Pillar. The icons you see in the menu are the apps that come with the system, and the ones you add yourself are easy to tell apart.

Microsoft fonts install themselves after setup

After you install Pillar and restart for the first time, connect the computer to the internet and leave it on for a few minutes. Pillar downloads Microsoft's free fonts (Arial, Times New Roman, Verdana, Georgia and others) in the background, once. You do not need to do anything. Until then, Pillar uses look-alike fonts that keep your documents laid out the same way. The Pillar system integrity check may list the new font files at the next start. That is expected.

Where it stands

Pillar 64 1.0 is the first public test build. It has been tested in VirtualBox, not yet across many real computers. If you try it on a real machine, back up your files first and expect rough edges. The FAQ lists what does not work yet. It has been installed on a Surface Pro 7, and the Surface page shows how to add touchscreen support.
