Included with Pillar 64

The apps

Every app on this page is made for Pillar and ships on the disc. None of them needs LibreOffice or any other office suite. Anything else you install yourself shows up with its own name and icon, so you can always tell the two apart.

Office and documents

Pillar Word

A word processor that opens and saves Word documents (.docx). Pillar includes metric-compatible fonts, so a document keeps its page breaks and layout.

Pillar Excel Sheet

A spreadsheet with formulas, cell formatting, sorting and more than 170 functions, including SUM, IF, VLOOKUP, dates and text. It opens and saves .xlsx, .xlsm, .csv and .ods files natively, reads older .xls files, and exports to PDF.

Not yet: charts and pivot tables. Binary .xlsb files are not supported.

Pillar PDF

Reads and edits PDF files. Highlight, underline, strike through, add notes and text, draw, add shapes and sign. Fill in forms, search, view page thumbnails, open and save password-protected files, print, and export pages as pictures. Rotate, delete, move, extract, merge and insert pages, and turn pictures into pages.

Not yet: changing the original text inside a PDF.

Pillar Mail

Outlook-style mail. Add several accounts, including Yahoo, Gmail and others, and read them together.

The web

Pillar Web

The Pillar browser, built on Firefox, with tracking and malware blocking turned on. Its promise: a foundation you can trust.

Pillar Remote Desktop

Connect to other computers over RDP or VNC, including Windows PCs.

Everyday tools

Pillar Start

The Start menu. Open it with the Windows key or Alt+F1.

Pillar Files

The file manager.

Pillar Photos

Browse and view your pictures.

Pillar Calculator

A calculator that matches the rest of the system.

Pillar Services

See and manage the background services running on the computer.

Drives and installing software

Pillar Disks

See every drive and how it is divided. Mount, unmount and eject, format (ext4, NTFS, exFAT, FAT32, Btrfs, XFS), rename, check, grow, create and delete partitions, make a new partition table, and read drive health (SMART). The drive Pillar runs from is locked so it cannot be changed by accident, and destructive actions ask you to type the device name to confirm.

Not yet: moving or shrinking partitions.

Pillar USB Creator

Makes a bootable USB drive from an ISO file. It only lists removable drives, verifies what it wrote, and has a Windows mode for installer discs. Please note that it does not yet support persistence (saving files on the USB itself).

Pillar Software

Find and install software.

Pillar Package Installer

Double-click a downloaded .deb file, such as Valve's Steam installer, and it installs. Steam is not preinstalled; you add it only if you want it.

No presentation app yet

Pillar does not include a slides app in this release. A Pillar presentation program is planned.
