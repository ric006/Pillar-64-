Install Pillar 64

From the download to a running desktop in six steps. Allow about 30 minutes, plus the time the 3.9 GB file takes to download.

  1. Download and check the file

    Get the ISO from the Download page, then compare its checksum with the one shown there. A mismatch means the file is damaged and should be downloaded again.

  2. Make an installer USB drive

    Use a USB drive of 8 GB or larger. Everything on it will be erased.

    On Windows: use a tool such as Rufus or balenaEtcher. In Rufus, choose the Pillar ISO, and if it asks how to write the image, choose DD Image mode.

    On Pillar or another Linux: open Pillar USB Creator, choose the ISO and the USB drive, and click write.

  3. Start the computer from the USB drive

    Plug in the drive, restart, and open the boot menu while the computer starts. The key depends on the maker. Common ones are F12, F2, Esc, F10 and Del. Choose the USB drive from the list. If the computer does not offer the drive, check that it is set to start in UEFI mode.

  4. Try or install

    Pillar starts into a live desktop from the USB drive, so you can look around before changing anything. Nothing is saved to the computer in this mode. When you are ready, start the installer from the welcome screen.

  5. Follow the installer

    Choose your language, keyboard and time zone, then where to install. Choosing to erase the disk replaces everything on it. Create your name, computer name and password, and let it finish. Restart when it asks and remove the USB drive.

  6. Connect to the internet and wait a few minutes

    On the first start of the installed system, connect to Wi-Fi or plug in a network cable. Pillar then downloads the Microsoft fonts package in the background, once. Nothing appears on screen. See Microsoft fonts for how to check that it worked.

Trying it in VirtualBox

VirtualBox is the easiest way to try Pillar without touching your computer. This is the setup Pillar 64 has been tested with:

  • 16 GB of memory, 4 processor cores, a 100 GB disk.
  • System: turn on EFI.
  • Display: video memory at the maximum (128 MB), graphics controller VMSVGA.

Video can look choppy inside a virtual machine, because the picture is drawn by the processor instead of a graphics card. On a real computer, video plays smoothly.

If something goes wrong

The USB drive is not offered at start-up
Try another USB port, rewrite the drive in DD Image mode, and check that the computer starts in UEFI mode.
The installer says a file is missing
The download is probably damaged. Check the checksum and download the ISO again.
The screen is blank after the logo
Restart and try again. If it repeats on a real computer, please let us know the make and model.
