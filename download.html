Connect to the internet after your first restart

Pillar downloads Microsoft's fonts by itself the first time the installed system starts with an internet connection. It runs in the background and takes a few minutes. If the computer is offline, Pillar tries again at every start until it works, then never runs again. The Pillar system integrity check may list the new font files at the next start. That is expected. Full details

Check your download

A large file can arrive damaged. Compare its MD5 checksum with the one above. If they match, the file is good. If they differ, download it again.

On Windows (Command Prompt or PowerShell)

certutil -hashfile "C:\Users\YourName\Downloads\Pillar64.iso" MD5

On Linux

md5sum ~/Downloads/Pillar64.iso

Change the folder and file name to match yours. The line of letters and numbers it prints must be the same as the checksum above.

Before you install

  • A USB drive of 8 GB or larger. Everything on it will be erased when you make the installer.
  • Back up your files if you plan to install on a real computer. This is the first public test build.
  • Tested setup. Pillar 64 has been tested in VirtualBox with 16 GB of memory, 4 processor cores, a 100 GB disk and UEFI start-up. Minimum requirements have not been measured yet.
  • Internet is only needed to fetch the Microsoft fonts after setup and for whatever you do online.
