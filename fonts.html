Fonts

Microsoft fonts

Pillar installs Microsoft's free fonts by itself, once, the first time the installed system starts with an internet connection.

The short version

After you install Pillar and restart, connect to the internet and wait a few minutes. That is all. The fonts arrive in the background, with no window and no menu entry. If you are offline, Pillar tries again at every start until it succeeds.

Why they are not on the disc

Microsoft's fonts (Arial, Times New Roman, Verdana and the others) are free to download, but their licence does not allow them to be copied onto another company's disc. So the Pillar ISO cannot include them. Pillar fetches them after setup instead, straight from the internet.

What you have from the first minute

The disc includes look-alike fonts designed to take exactly the same space as the Microsoft ones. A document keeps the same line breaks and page breaks, even before the real fonts arrive.

What happens after you install

  1. You restart into the installed systemNothing visible happens. Pillar checks whether the fonts have already been installed.
  2. The computer is onlineA small background task starts, accepts Microsoft's font licence for you, and downloads the package. This takes a few minutes, depending on your connection.
  3. The fonts are installedPillar refreshes the font list and records that the job is done. It never runs again.
  4. The next integrity check lists the new fontsAt the next start-up the Pillar system integrity check may report the new font files as changes. That is expected.
  5. Restart your appsClose and reopen Pillar Word and any other open program to see the new fonts in their lists.

If the computer is offline

Nothing breaks. The task stops quietly and tries again at the next start. It keeps trying, once per start, until a connection is there and the download succeeds.

Which fonts you get

The package installs these Microsoft web fonts: Andale Mono, Arial, Arial Black, Comic Sans MS, Courier New, Georgia, Impact, Times New Roman, Trebuchet MS, Verdana and Webdings.

It does not include Calibri, Cambria, Consolas or Segoe UI. Microsoft does not offer those for free download. Pillar uses the look-alikes above for Calibri and Cambria.

Only on the installed system

This happens on a computer where Pillar has been installed. When you run Pillar from the USB drive without installing, the live desktop forgets everything when you shut down, so nothing is downloaded there.

The integrity check will notice them

Pillar checks its own system files each time the installed system starts, and shows the result on the start-up screen. The first start after installation sets the starting point. The fonts arrive after that, so the next check can list the new font files as changes.

This is expected. It is the check doing its job. It does not mean anything is damaged or unwanted. If a check ever lists files that are not fonts, take that one seriously.

To read the latest result yourself:

cat /var/log/pillar-integrity.log

Check that it worked

Open a terminal and list the font folder. If you see files like Arial and Verdana, it worked.

ls /usr/share/fonts/truetype/msttcorefonts

To see the job itself:

systemctl status pillar-ms-fonts.service

If it has not finished, the line to read the details is:

journalctl -u pillar-ms-fonts.service

A note on the licence and on privacy

The font package comes with a Microsoft licence. Pillar accepts it on your behalf so that the install can run without a window. By installing Pillar and connecting to the internet you are agreeing to that licence for these fonts.

This download is the one thing Pillar fetches on its own. It sends no usage data, and Pillar does not install or update anything else without you.

Prefer not to have the fonts? Turn the task off before you first connect, and Pillar will keep using the look-alike fonts:

sudo systemctl disable --now pillar-ms-fonts.service

To install them later, run this and the task does the rest:

sudo systemctl start pillar-ms-fonts.service
